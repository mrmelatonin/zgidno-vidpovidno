# Згідно-Відповідно (`zgidno-vidpovidno`)

**Автономний скіл (Skill) для ШІ-асистентів Antigravity, Gemini CLI та Claude Code.**

Призначений для професійного створення, верстки, редагування та нормативної валідації українських службових та управлінських документів відповідно до:
- **Інструкції з діловодства** (Наказ Міністерства оборони України № 638/2023 та Додатки 1–30);
- **ДСТУ 4163:2020** «Уніфікована система організаційно-розпорядчої документації. Вимоги до оформлення документів».

---

## ⚡ Швидке встановлення

### Спосіб 1: Автоматичне встановлення в 1 рядок (Windows PowerShell)

Відкрийте PowerShell і виконайте:
```powershell
irm https://raw.githubusercontent.com/mrmelatonin/zgidno-vidpovidno/main/install.ps1 | iex
```

### Спосіб 2: Автоматичне встановлення в 1 рядок (Linux / macOS Bash)

Відкрийте термінал і виконайте:
```bash
curl -sSL https://raw.githubusercontent.com/mrmelatonin/zgidno-vidpovidno/main/install.sh | bash
```

### Спосіб 3: Вручну через Git Clone

#### Глобально для всіх проєктів (Global Skill):
```bash
git clone https://github.com/mrmelatonin/zgidno-vidpovidno.git ~/.gemini/config/skills/zgidno-vidpovidno
```

#### Лише для поточного проєкту (Workspace Skill):
У корені вашого репозиторію виконайте:
```bash
git clone https://github.com/mrmelatonin/zgidno-vidpovidno.git .agents/skills/zgidno-vidpovidno
```

## 🚀 Як користуватися

Після встановлення скіл автоматично підключається до вашого ШІ-асистента. Вам достатньо звернутися з природним запитом у чаті:

- **Створення службового листа:**
  > *«Склади проєкт службового листа до Мінцифри про проведення спільної робочої наради. Автор — Департамент зв'язку, виконавець — Тарас Коваль, тел. 223-45-67.»*
- **Складання доповідної записки або протоколу:**
  > *«Підготуй протокол засідання робочої групи з трьох питань порядку денного з розділами СЛУХАЛИ, ВИСТУПИЛИ, ВИРІШИЛИ.»*
- **Спеціальні профілі (Президент / Мін'юст):**
  > *«Оформи цей наказ для подання на державну реєстрацію до Мін'юсту (14 pt, 1,5 інтервал).»*
  > *«Підготуй звернення Президенту України (А4, 16 pt, 1,5 інтервал).»*
- **Аудит та перевірка:**
  > *«Перевір файл document.docx за чек-листом діловодства та виправ порушення.»*

## 🛠 Автоматична валідація DOCX-файлів

У репозиторії є автономний скрипт на Python для швидкої перевірки геометрії сторінок, шрифтів, кеглів та лапок:

```bash
# Стандартний документ (поля 30/10/20/20 мм, Times New Roman 12–14 pt, лапки “”):
python scripts/validate_docx.py "шлях/до/документа.docx"

# Перевірка за спецпрофілем Президента (16 pt, 1,5 інтервал):
python scripts/validate_docx.py "документ.docx" --profile president

# Перевірка за спецпрофілем Мін'юсту (14 pt, 1,5 інтервал):
python scripts/validate_docx.py "документ.docx" --profile minjust

# Вивід у форматі JSON для CI/CD автоматизації:
python scripts/validate_docx.py "документ.docx" --json
```

## 📋 Базові константи стандарту (Quick Reference)

| Параметр | Значення | Норматив |
|:---|:---|:---|
| **Поля сторінки** | Ліве — **30 мм**, праве — **10 мм**, верхнє/нижнє — **20 мм** | Д 6.2; І 118 |
| **Основний шрифт** | Times New Roman, **12–14 pt** (базовий 14 pt, інтервал 1,0) | А, дод. 8, п. 1–2 |
| **Профіль Президенту** | А4, Times New Roman **16 pt**, інтервал **1,5** | А, дод. 8, п. 2 |
| **Профіль Мін'юсту** | Times New Roman **14 pt**, інтервал **1,5** | А, дод. 8, п. 2 |
| **Лапки** | **Виключно лапки “”** (заборонено «» та "") | Стандарт діловодства |
| **Абзацний відступ** | **10 мм** від лівого поля (40 мм від краю аркуша) | А, дод. 8, п. 4 |
| **Відступ адресата** | **90 мм** від лівого поля (120 мм від краю аркуша) | А, дод. 8, п. 5 |
| **Відступ грифа** | **100 мм** (одиночний), **104 мм** (другий гриф) | А, дод. 8, п. 6–8 |
| **Відступ підпису** | **125 мм** від лівого поля (155 мм від краю аркуша) | А, дод. 8, п. 9 |
| **Формат підпису** | Власне ім'я та **ПРІЗВИЩЕ ВЕЛИКИМИ** (без ініціалів) | Д 5.22 |
| **Бланк** | **Тільки на першій сторінці** | А, дод. 8, п. 12 |
| **Перенесення підпису** | **Мінімум 2 рядки основного тексту** перед підписом | А, дод. 8, п. 12 |
