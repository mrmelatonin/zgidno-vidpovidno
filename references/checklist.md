## 2. Стандартизовані статуси оцінки

- **відповідає** — вимога виконана в повному обсязі.
- **потребує виправлення** — виявлено відхилення від стандарту (вказати пункт норми та необхідну дію).
- **не застосовується** — норма не стосується цього виду документа (наприклад, відсутність додатків чи бланка для записки).
- **неможливо перевірити** — відсутні фактичні дані чи повноваження підписувача (не прирівнювати до відповідності!).

## 3. Формат запису зауважень (Audit Issue Log)

У разі виявлення порушень оформлювати звіт у такому вигляді:

```text
[Реквізит / Сторінка] -> [Виявлене відхилення] -> [Пункт стандарту] -> [Необхідне виправлення]
Приклад:
- Підпис / Стор. 2 -> Вказано ініціали “Т.Г. Шевченко” -> ДСТУ 4163:2020, п. 5.22 -> Замінити на “Тарас ШЕВЧЕНКО”
- Поля / Стор. 1 -> Ліве поле становить 20 мм -> Інструкція, п. 118 -> Збільшити ліве поле до 30 мм
```
