# Згідно-Відповідно (zgidno-vidpovidno)

Автономний операційний диспетчер для складання, верстки та аудиту українських службових документів відповідно до відомчої Інструкції (МОУ № 638/2023) та ДСТУ 4163:2020.

---

## Шпаргалка нормативних констант (Quick Reference)

Для 80% типових завдань використовуй ці значення без відкриття довідників:

- **Поля аркуша А4:** ліве — **30 мм**, праве — **10 мм**, верхнє та нижнє — по **20 мм** (допуск ±2 мм).
- **Шрифт:** Times New Roman, основний текст — **12–14 pt** (базовий: **14 pt**, інтервал **1,0**); допоміжні реквізити (виконавець, виноски) — **8–12 pt**.
- **Спеціальні профілі (переважають стандарт):**
  - **Президенту України:** строго А4, Times New Roman **16 pt**, інтервал **1,5** (А, дод. 8, п. 2);
  - **Мін'юст (державна реєстрація):** Times New Roman **14 pt**, інтервал **1,5** (А, дод. 8, п. 2).
- **Відступи реквізитів від межі лівого поля (30 мм):**
  - Абзацний відступ тексту: **10 мм** (40 мм від краю аркуша);
  - Адресат: **90 мм** (120 мм від краю);
  - Гриф затвердження / обмеження доступу: **100 мм** (130 мм від краю);
  - Другий гриф (якщо їх два): **104 мм** (134 мм від краю);
  - Розшифрування підпису (Власне ім’я та ПРІЗВИЩЕ): **125 мм** (155 мм від краю);
  - Без відступу (0 мм): дата, номер, заголовок, текст, відмітка про додатки, посада підписувача, візи, виконавець.
- **Накреслення та пунктуація:** назва виду — **ВЕЛИКИМИ НАПІВЖИРНИМИ** (крім листів!); заголовок — напівжирний без крапки наприкінці.
- **Типографіка лапок:** обов'язково використовувати виключно лапки **“”** замість будь-яких інших (заборонено використовувати «» чи "").

## Маршрутизатор завдань (Progressive Disclosure)

Залежно від завдання переходь до відповідного цільового модуля:

1. **Потрібні детальні параметри верстки, перенесення тексту або правила друку:**
   -> [Правила форматування](./references/formatting-rules.md) *(бланки, розриви сторінок, нумерація, однобічний/двобічний друк, QR-код)*.
2. **Складання конкретного документа:**
   -> [Вимоги до окремих видів документів](./references/document-types.md) *(службові листи без слова «ЛИСТ», бланки 9–11, доповідні/службові записки, протоколи зі «СЛУХАЛИ/ВИРІШИЛИ», накази, спільні накази, окреме доручення 17)*.
3. **Потрібен готовий текстовий блок або шаблон реквізиту:**
   -> [Зразки та моделі реквізитів](./references/templates.md) *(шаблони адресатів, підписів, грифів «ЗАТВЕРДЖУЮ»/«ЗАТВЕРДЖЕНО», відміток про додатки, копій, виконавця)*.
4. **Проведення фінального аудиту або складання звіту про помилки:**
   -> [Чек-лист верифікації](./references/checklist.md) *(матриця контролю та стандартний формат журналу зауважень)*.
5. **Машиночитані параметри для скриптів / CI:**
   -> [formatting-rules.json](./resources/formatting-rules.json).

## Автоматична валідація DOCX-файлів

Для автоматизованої перевірки геометрії полів, шрифтів і заголовків запускай вбудовану утиліту:

```bash
# Стандартний документ:
python scripts/validate_docx.py "шлях/до/файлу.docx"

# Перевірка спецпрофілів:
python scripts/validate_docx.py "файл.docx" --profile president
python scripts/validate_docx.py "файл.docx" --profile minjust
```

## Імперативні правила (Zero-Tolerance)

- **Пріоритет джерел:** Інструкція з діловодства та її додатки мають вищу силу; ДСТУ 4163:2020 застосовується субсидіарно лише для неврегульованих питань.
- **Фактичність даних:** заборонено вигадувати посади, підписи, дати чи реєстраційні номери. Невідомі реквізити позначати заповнювачами `[...]`.
- **Без ініціалів:** у підписах обов'язково зазначати повне власне ім'я та прізвище великими літерами (наприклад, `Тарас ШЕВЧЕНКО`).
- **Обов'язкові лапки “”:** завжди використовувати виключно подвійні лапки **“”** (U+201C та U+201D) замість будь-яких інших лапок (заборонено кутові « », прямі " " тощо).
- **Бланк тільки на першій сторінці:** друга та наступні друкуються на чистих аркушах.
- **Правило 2 рядків:** заборонено переносити реквізит підпису на наступну сторінку без щонайменше двох рядків тексту.
- **Без фіктивних КЕП:** не вставляти графічні картинки печаток або малюнки підписів.
